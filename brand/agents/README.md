# Agent marks

Each file here is the mark of a coding agent hippo reads, used in Hippo.app, the site, the live demo and the README only to say which agent a session came from. The marks belong to their owners; their use here implies no endorsement.

All eight come from `@lobehub/icons-static-svg` 1.104.0 (LobeHub's icon set, MIT, [LICENSE-lobe-icons.txt](LICENSE-lobe-icons.txt)). Changes: the `width` and `height` set to 24, the `style` attribute and the `<title>` removed. Each is one colour, `fill="currentColor"`, so it takes the colour of the text around it.
