# Eval baseline, 2026-11-08

The first baseline of [`hippocamp eval`](../site/src/eval.md): one `--with-model` run of the v1 set with the real `claude` CLI. Every number from the dreaming suite is one sample; a later run with the same model can differ by a correction or two. The set is small and synthetic and has one author, so these numbers describe this set, not hippocamp in general.

## How it was run

- **Command**, in a clean checkout of the commit below, with the binary built from that commit:

  ```sh
  HIPPOCAMP_HOME=<temporary directory> cargo run --release --locked -p hippocamp -- eval fixtures/eval --with-model
  ```

  `HIPPOCAMP_HOME` was a temporary directory holding only the `config.toml` below (eval reads nothing else from it and writes nothing to it), and `CLAUDE_CONFIG_DIR` named a signed-in Claude Code profile. In this file `<tmp>` stands for that run's temporary directory; the `workspace` it names is an empty directory, which `config.toml` must name and eval does not use.
- **Commit**: a clean checkout of `main` at hippocamp 0.0.1, before the current version; the context and recall numbers of 0.1.0 are on the [eval page](../site/src/eval.md).
- **`model_command`**: the default, with `--model claude-opus-5-5` added, as `config.toml` below shows; the model it pins is the one the CLI reported, below.
- **`config.toml`**:

  ```toml
  workspace = "<tmp>/workspace"
  model_command = [
    "claude", "-p", "--no-session-persistence", "--setting-sources", "", "--tools", "",
    "--strict-mcp-config", "--system-prompt", "{system_prompt}", "--output-format", "json",
    "--model", "claude-opus-5-5",
  ]
  ```

- **`claude --version`**: `2.1.319 (Claude Code)`.
- **Model**: `claude-opus-5-5`, the key of `modelUsage` in the JSON output of a one-word run with the same flags (`claude -p --no-session-persistence --setting-sources "" --tools "" --strict-mcp-config --system-prompt "Reply with one word." --output-format json "Say ok"`).
- **Machine**: an Apple silicon Mac.
- **Date**: started 2026-11-08T09:21:36Z, finished 2026-11-08T09:23:14Z; wall time 98 seconds. Eval exited with 0.
