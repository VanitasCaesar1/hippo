hippo

One brain for all your coding agents.

Your Claude Code sessions start from the same plain-Markdown notes and write back to them, and at night a second, fresh-context reviewer checks every proposed change to those notes against what your agents actually did. Underneath, hippo indexes every Claude Code and Codex session on your machine, so you can search them, see your agents' day, and share it.

Install

macOS (Apple silicon or Intel), one line, no sudo (installs to ~/.local/bin):

curl -fsSL https://raw.githubusercontent.com/VanitasCaesar1/hippo/main/install.sh | sh

Inside Claude Code, /plugin marketplace add VanitasCaesar1/hippo then /plugin install hippo@hippo. On Linux, or with Rust, cargo install --locked --git https://github.com/VanitasCaesar1/hippo hippo. More on installing.

The first two minutes

  1. hippo lists the agent history it finds. Nothing is written yet.
  2. hippo start --yes indexes it (history only, nothing sent), then shows your last active day.
  3. hippo card turns that day into a 1200 x 675 PNG to share.

The overview gives the day's sessions and sub-agents, the agents' work time, how long they waited on you, the pull requests they merged, the times you corrected them, the busiest sessions, and four commands to try next.

What it does

  1. Search every past session. hippo ask --sources-only "<question>" ranks the sessions that dealt with it; hippo recall searches every turn.
  2. See the day. hippo, fleet, incidents, xray, and card for one image.
  3. A shared brain your agents start from and write back to. init sets up a notes folder, hooks install gives every Claude Code session its notes, brief gives any agent a start block.
  4. Kept true at night. dream checks notes against transcripts; a second reviewer confirms every change, and revert undoes any of them.
  5. Packs you copy and own. hippo add copies passes, prompts and personas into your workspace after a review. They are files, never code.

How it differs

  • Your notes are plain Markdown files in your own folder. The index is a local SQLite file.
  • No change lands without a fresh-context review.
  • Every change can be undone.

What leaves your machine

hippo's own code makes no network calls. Data leaves only through the model command (by default claude -p, under your login), which dreaming, written answers from ask, pack reviews and a few named checks run, and through git, when you fetch a pack. Everything else, including hippo, start, card, recall and ask --sources-only, is local. Security and privacy.
