hippo, as in hippocampus

Your coding agents learn while you sleep

Every night hippo reads the day's sessions from every agent you run, drafts rules from what you had to say twice, and has a second model check each one against what happened. Keep a rule, and tomorrow every session starts with it.

What it does

  • A night pass with a reviewer

    Each night a model reads the day's sessions and drafts note fixes and rules. A second model with a fresh context must confirm each one against the turns it cites.

  • An Inbox, not autopilot

    Rules drafted from your corrections and from repeated failures wait for you to keep, edit or dismiss. Nothing becomes a rule on its own.

  • A start block per task

    A new session gets the entry note, the required notes and the notes its task needs, about 1.5 KB under a hard budget. Not the whole pile.

  • Every agent, and MCP

    Reads Claude Code, Codex, Cursor, Gemini CLI, OpenCode, DeepSeek Harness, Muse Code and Command Code. Any MCP client can ask through hippo mcp.

  • Guard and secrets

    Flags, by rule and with no model, an agent piping an installer from the internet or reading a credential file. Secrets are redacted before anything is indexed.

  • Receipts and revert

    Every applied change leaves a receipt and a snapshot. One command, hippo revert, puts the note back.

Questions

Does anything leave my machine?

hippo's own code has no HTTP client. Data leaves through the model command it runs for the nightly pass and for written answers (by default claude -p, under your own login), through git when you fetch a pack, and through curl when you install hippo or Hippo.app. Transcript text is redacted when it is indexed, by pattern, best effort.

Is it safe?

hippo puts hooks in your agents and runs a model at night, so every hook, MCP tool, program it starts and host it can reach is listed in Is it safe?, and a test fails when the code gains one the page does not name.

Which agents does it work with?

It reads sessions from Claude Code, Codex, Cursor, Gemini CLI, DeepSeek Harness, OpenCode, Muse Code and Command Code. The first six get the notes when a session starts. Any other MCP client can ask for the notes through hippo mcp; its history is not read.

Can it write something wrong into my notes?

It can propose something wrong. A second model that never sees the first one's reasoning has to confirm each change. On the repository's eval set that fixed 3 of 7 planted errors and damaged 0 of 8 correct notes. Every applied change has a receipt, and hippo revert undoes it.

What does a night cost?

It depends on how many sessions the day had. The pass runs under your own agent login, so it counts against that account. hippo dream --dry-run proposes changes without applying any.

Is there an app?

Hippo.app, for macOS: hippo app install downloads it, checks its sha256 and puts it in ~/Applications. It is signed ad hoc, not notarised. Everything it shows has a command behind it, so the CLI alone is enough. The live demo is a replica of two of its screens with made-up data.

How does a team share it?

Through git. Notes and receipts are files in the repository; what your own agents did stays ignored. Nothing syncs live.

Does it make agents better?

That has not been measured. hippo is one person's project at v0.7.1, used daily on macOS; Linux is tested in CI.

Install

macOS and Linux

$curl -fsSL https://raw.githubusercontent.com/VanitasCaesar1/hippo/main/install.sh | sh

Claude Code plugin, then /hippo:setup

/plugin marketplace add VanitasCaesar1/hippo

Codex plugin

$codex plugin marketplace add VanitasCaesar1/hippo
$codex plugin add hippo@hippo

Hippo.app, macOS

$hippo app install

DeepSeek Harness plugin

$dsh plugin --profile web add "github:VanitasCaesar1/hippo#v0.7.1&path:/plugins/dsh"

OpenCode plugin, in opencode.json

"plugins": ["github:VanitasCaesar1/hippo#v0.7.1::path:plugins/opencode"]

From source

$cargo install --locked --git https://github.com/VanitasCaesar1/hippo hippo

More on installing

Limits

  • Muse Code and Command Code sessions are read, but those agents are not given the notes yet.
  • Used daily on macOS. Linux is tested in CI, not in daily use.
  • The nightly schedule is launchd on macOS; elsewhere hippo prints cron and systemd lines for you to install.
  • Whether it makes agents' work better is not measured.
