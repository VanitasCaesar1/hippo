See what your coding agents did, from the history already on your machine

For people who run a lot of Claude Code and Codex sessions at once. hippo shows which one is waiting on you and quotes each time you had to correct one. Keep a correction and it goes into the notes the next session starts from.

install

$curl -fsSL https://raw.githubusercontent.com/VanitasCaesar1/hippo/main/install.sh | sh

macOS or Linux, no sudo. MIT. Click the line to select it, or see the plugin and cargo installs.

What it touches on your machine

No account and no server. The index is a SQLite file, and the one way text leaves is a model call made through the claude -p login you already have.

reads

~/.claude*/projects/

Claude Code session history

~/.codex/sessions/

Codex session history

writes

~/.hippo/index.sqlite

the index, a local SQLite file

notes/*.md

your notes, in a folder you choose

.hippo/receipts/

one receipt per reviewed change

.hippo/snapshots/

the note as it was, for hippo revert

sends

claude -p

nightly checks and written answers, through your own login. Nothing else leaves.

Before you do

  • It reads Claude Code and Codex. Nothing else yet.
  • I use it every day on macOS. Linux is tested in CI.
  • Nobody has measured whether it makes agents better, me included.
  • One person built it, for a setup with a lot of agents in it.
  • v0.1.0, MIT licensed.
