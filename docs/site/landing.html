Your coding agents learn while you sleep

Every night hippo goes through the day's sessions from every agent you run and turns what went wrong into rules. A second model checks each one against what actually happened. Keep a rule, and tomorrow every session starts already knowing it.

Install

macOS and Linux

$curl -fsSL https://raw.githubusercontent.com/VanitasCaesar1/hippo/main/install.sh | sh

Claude Code plugin

/plugin marketplace add VanitasCaesar1/hippo
/plugin install hippo@hippo

DeepSeek Harness plugin

$dsh plugin --profile web add "github:VanitasCaesar1/hippo#v0.4.0&path:/plugins/dsh"

OpenCode plugin, in opencode.json

"plugins": ["github:VanitasCaesar1/hippo#v0.4.0::path:plugins/opencode"]

From source

$cargo install --locked --git https://github.com/VanitasCaesar1/hippo hippo

More on installing

Limits

  • Claude Code, Codex, DeepSeek Harness, OpenCode, Muse Code and Command Code only. Muse Code and Command Code are read, not given the notes.
  • Used daily on macOS; Linux is tested in CI.
  • Not measured whether it makes agents better.
  • Built by one person for their own many-agent setup. v0.4.0, MIT.
