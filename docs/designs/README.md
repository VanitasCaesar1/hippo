# Design documents

New designs go here, one Markdown file per feature or contract, written for a public reader before the code: the problem, what changes for a user, the record formats it touches, the alternatives and why they lost. Discuss one in an issue or a pull request before building it.

How hippocamp works today is described in [Architecture](../site/src/architecture.md) and the rest of the [documentation](../site/src/introduction.md).
